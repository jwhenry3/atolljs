atoll — the Worker Atoll

Worker pools and shared workers joined to your app through one shared-memory fabric. Contracts share fixed-layout SharedArrayBuffer state across threads; work is offloaded via task commands and state reactivity.

Package Docs ./consumer/

Consumer guide for @atolljs/core — install, quickstart, public API, framework bindings (React, Vue, SolidJS, Svelte, Angular, Next.js), worker islands, and hosting headers.

Internals Docs repo → docs/

Architecture and internals as in-repo markdown — contract schema, fixed-layout memory, worker pool and task dispatch, reactivity, shared workers, the islands engine, and cross-origin isolation.

GitHub Pages can't send cross-origin isolation headers itself, so the demos get them from coi-sw.js — a service worker that injects COOP/COEP into every response (the first visit reloads once to pick it up). Where isolation still isn't available the worker-islands demo runs on its poll transport, and the shared-memory demos show a notice — run npm run dev:all or npm run serve:all locally for the guaranteed-live version.

mesh — the Worker Mesh

Worker pools and shared workers joined to your app through one shared-memory fabric. Contracts share fixed-layout SharedArrayBuffer state across threads; work is offloaded via task commands and state reactivity.

SDK Docs ./sdk/

Architecture and internals — contract schema, fixed-layout memory, worker pool and task dispatch, reactivity over Atomics version counters, shared workers, and cross-origin isolation.

Package Docs ./consumer/

Consumer guide for @jwhenry123/mesh — install, quickstart, public API, framework bindings (React, Vue, SolidJS, Svelte, Angular, Next.js), and hosting headers.

Live demos embedded in the docs require cross-origin isolation (Cross-Origin-Opener-Policy + Cross-Origin-Embedder-Policy), which GitHub Pages cannot send — the iframes will be inert here. Run npm run dev:all or npm run serve:all locally to see them live.
